# lab-assignment-KRMU-web-dev-1


---

**Wanderlust Travel Website**

A completely responsive, static travel-focused website created using HTML5 and CSS3.
This project highlights proper semantic markup, adaptable page structures (Flexbox & Grid), accessibility practices, and a clean modern interface.

---

### 🌍 **Concept**

**Travel Agency Webpage**

Built to display popular destinations, travel packages, and an eye-catching hero section that delivers a professional travel-service feel.

---

### ✨ **Key Highlights**

**1. Semantic Web Structure**

* Uses elements like `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`
* Includes accessible navigation menus and descriptive alt text for images

**2. Responsive Design Implementation**

* Flexbox applied to the header and footer for flexible alignment
* CSS Grid used for destination and package cards
* Optimized for multiple screens, including:

  * Desktop (1024px and above)
  * Tablet (~768px)
  * Mobile (480–600px and below)

**3. Modern UI Styling**

* Prominent hero section with a clear call-to-action
* Card-style layout for showcasing locations and offers
* Smooth hover effects and transitions
* Customized color scheme and typography
  
**4. Resources & Files**

* Images placed inside the `images/` directory
* Styling handled through an external `style.css` file
