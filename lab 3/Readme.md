**Lab Title: Personal Portfolio Website**

**Description**
In this lab, students will design a fully responsive personal portfolio website using HTML and CSS.
The site highlights the learner’s profile, abilities, completed work, and a functional contact form.
It also reflects an understanding of modern UI/UX practices such as structured layouts, responsive styling, box designs, shadow effects, and clean visual presentation.

The portfolio will contain the following sections:

* A header with a navigation bar
* A hero area featuring an introduction and profile photo
* An About Me section
* A Skills section with styled skill blocks
* A Projects section showing project cards
* A Contact form for communication
* A footer

This lab enables students to build practical front-end development skills and learn how to organize and style a complete webpage from the ground up.
